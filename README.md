# 💼 Kişisel Portfolyo Projesi (.NET Core 6.0)

Geliştirdiğim dinamik bir portfolyo uygulamasıdır. Proje, modern yazılım geliştirme prensiplerine uygun olarak hazırlanmış, yönetim paneli ve kullanıcı arayüzü olmak üzere iki ana yapıdan oluşmaktadır.


## 🚀 Kullanılan Teknolojiler

- **ASP.NET Core 6.0** – Web uygulama çatısı
- **Entity Framework Core (Code First)** – Veritabanı işlemleri (MS SQL Server)
- **Razor Pages / Views**
- **ViewComponent** – Veri + görünüm bileşenleri
- **PartialView** – UI parçalanması
- **LINQ** – Veri sorgulama ve analiz
- **Google Maps API** – Harita entegrasyonu
- **SweetAlert** – Bildirimler
- **Tek Katmanlı Mimari**
